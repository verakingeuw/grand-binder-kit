# grand-binder-kit

DevOps engineer · Ansible and Terraform

给自己省点事的小工具

## 用法

```bash
cat data.txt | ./run.sh
```

输出：

```
   3  error: timeout
   1  warn: retry
---
2 unique / 4 lines
```

## 为什么写

现有的工具都太重，就想要个能管道拼接的小东西。

## 安装

```bash
git clone https://github.com/USER/grand-binder-kit.git
cd grand-binder-kit
chmod +x run.sh
```
